1 · The same question, twice, with one thing changed

Task T3 — are the failures scattered, or concentrated?
Persona P1, the engineer
Views map → inspector
~6 minutes

A table tells you how many blind spots there are. It cannot tell you whether they are anywhere in particular — and that is the difference between “2.8% of our questions fail silently”, which sounds like a rounding error you accept, and “our failures have a describable shape”, which is something you can route around.

Are the red dots even?in the tool

No — and the size of the effect matters. Blind spots sit closer to one another than chance: the average distance to the nearest other blind spot is shorter than for a random sample of the same size, by a modest margin.

Real, and modest. This does not say “tightly clustered”. It says “not uniform” — enough to justify looking.

The blind-spot rate does not track how often they are wrong. It tracks how often they are wrong together. One possible reason, not tested: nobody famous is attached to a film’s producer, so the models guess — and guess differently. Disagreement catches them.

What this path reaches

A third failure mechanism. The project had obscurity (never learned it) and misconception (learned something false). This is neither: the model knows the fact and attaches it to the wrong referent. A plausible explanation, not tested directly: every model resolves toward fame because the famous one dominates the web they learned from — so they fail identically, which is exactly the condition disagreement cannot see.

And the limitation, on the same path

Some of these are not model errors. The honest statement of the 950 is: questions where every model agreed and every model was marked wrong — some genuine shared failures, some ambiguous questions where the models chose a defensible different referent, a few stale or over-strict keys.

This is a strength, not a hole. It is the benchmark curator’s question arriving unbidden while running the engineer’s. One path, two tasks, and the second was not designed for. The 54 answer-key flags bound part of it, but they only catch shorter-form answers — nothing automatic catches “right about a different Robin Williams”.

6

So state it as a bound, not a numberscript

The answer-key flag cannot measure the contamination: it requires every model to have given a short form, and here the whole mechanism is that one did not. It fires on only a handful of the 125 — answering a different question.

Two string-similarity heuristics were tried while drafting this and both failed: verbose 2024 answers contain the 2025 wrong answer as a substring, so containment marks genuine regressions as artifacts. Both produced a count; neither was published.

As graded, at most 125 of 630 newly-hidden cases are genuine regressions, and hand-checking suggests meaningfully fewer. No test in this project reliably measures the contamination — the artifact and the regression are the same string pattern, and only reading the case separates them.

The two walkthroughs are one finding from two directions

Walkthrough 1: at a fixed moment, “director of X” questions whose bare title is already taken on Wikipedia fail silently 6.9× as often as those whose title is unique.
Walkthrough 2: in the cases read here, across a generation, models drift toward the famous answer, and their disagreement disappears with it.

The upgrade (newer and larger at once, so the two cannot be separated) mostly did not create new ignorance. It made existing ignorance agree with itself.

What this proves about the tool — and what it does not

Does: steps 2, 3 and 5 of walkthrough 2 are pure interface, and step 1 only reads the tool's generation chart. Holding one question fixed and flipping the generation is not something a table does, and the two cases carrying that path are individually surprising rather than aggregate facts. This is the strongest evidence in the project that the tool is necessary rather than decorative.

Every step that is a link is exactly reproducible. The tool's whole view — colouring, legend filter, dataset selection, and the box in data coordinates rather than pixels — lives in the URL, so the same link is the same screen on any display at any size. That also fixes something the evaluation needed: three reviewers can be given provably identical starting views instead of three descriptions of one. The Copy link to this view button in the map sidebar makes one from wherever you are.

Does not: the counts are scripts. The tool shows you a case; it will not tell you how many cases look like that one. That division is legitimate — a visual-analytics tool is judged on supporting discovery, and confirmation is a separate act — but a walkthrough has to say which is which.
